# Section Editor

Use the Section Editor to curate how a section's visuals, narration, motion, and
annotations work together. The canvas shows the visual selected for editing
when playback is stopped and the visual active at the playhead during playback.

## Select a visual

Select a visual tab or click its row in **Visual Timing / Details**. The selected
visual becomes the editing canvas and is used by crop, Focus, overlay, callout,
and reorder controls.

During playback, the active playback visual may differ from the visual selected
for editing. This lets playback follow the section timeline without discarding
your editing selection. Stop playback to return the canvas to the selected
visual.

## Reorder visuals

Select a visual, then choose **Move Visual Earlier** or **Move Visual Later**.
The visual moves with its authored duration. The section updates:

- playback order;
- Visual Timing / Details; and
- Callout Sequence numbering.

The selected visual remains selected after it moves. Preview the section to
confirm the revised storytelling order.

## Continue callout numbering across visuals

Numbered callouts normally use **This visual only**, so numbering starts again
on each visual. To continue a flow across a section, select a numbered callout
and choose or create a Callout Sequence.

For example, one sequence can display:

- Visual 1: 1, 2
- Visual 2: 3
- Visual 3: 4, 5

**Callouts in the same sequence continue numbering across visuals in this
section.** Each sequence begins at 1 and remains independent of other sequences.
Reordering visuals updates member numbering to follow the new visual order.
Choose **This visual only** to remove a callout from its sequence and return it
to visual-local numbering.

## Customize a Highlight

Select a Highlight to open **Highlight Appearance**:

- **Highlight Color** opens the macOS color control.
- **Transparency** controls how strongly the Highlight covers the visual.
- **Reset to Default** restores the original Lyreline yellow appearance.

Higher transparency lets more of the original visual show through. Each
Highlight keeps its own appearance, which carries through previews, video
export, PDF, HTML, and supported authored-document output.

## Preview the section

Use Section Preview to check visual order, Visual Cue timing, narration pauses,
callout numbering, Highlights, Focus, and motion together. Use Final Video
Preview before export to review the complete presentation.
