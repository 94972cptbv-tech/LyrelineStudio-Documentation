# Testing Lyreline Studio 1.4

Thank you for helping test Lyreline Studio 1.4. Use an existing project when
possible so compatibility and persistence are exercised along with the new
authoring controls.

## What to test

- Edit narration. Verify normal typing, caret placement, selection, Undo, and
  Redo.
- Select a narration phrase, attach a Visual Cue, and confirm its visual appears
  at the expected narration point. Adjust the timing when useful.
- Insert a narration pause and confirm it sounds natural in Section Preview and
  Final Video Preview.
- Reorder visuals in the Section Editor and confirm playback, Visual Timing, and
  Callout Sequence numbering follow the new order.
- Create a numbered Callout Sequence spanning several visuals.
- Change a Highlight's color and transparency, then use **Reset to Default**.
- Save, close, and reopen an existing project. Confirm edits and styling remain.
- Export a short video and inspect narration timing, visual order, callouts, and
  Highlights.
- If your workflow uses them, verify PDF, HTML, and authored-document output.

Report unexpected playback, editing, export, or persistence behavior. Include
the Lyreline Studio version/build, macOS version, steps, expected result, and
actual result. Do not include confidential project data or credentials.
