# What to Test in Lyreline Studio 1.5

Thank you for helping test Lyreline Studio 1.5. This release updates OpenAI
narration while preserving the established authoring, synchronization, preview,
and export workflow.

## What to test

- Generate OpenAI narration with the `marin` voice.
- Listen for faithful wording and natural pacing.
- Verify Visual Cue timing.
- Insert an authored Pause.
- Verify Section Preview.
- Verify Final Video Preview.
- Export a short MP4 and inspect the result.
- Open an older project and confirm its previously generated narration still
  plays.
- Verify Apple Speech still works normally.

Report any missing or added words, connection errors, playback issues, or export
differences. Include the Lyreline Studio version/build, macOS version, steps,
expected result, and actual result. Do not include confidential project data or
credentials.

Use the [Feedback](feedback.md) form or email
[lyreline.support@icloud.com](mailto:lyreline.support@icloud.com).
