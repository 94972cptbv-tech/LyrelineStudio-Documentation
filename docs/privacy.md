# Privacy Policy

**Last Updated: August 2026**

This policy describes Lyreline Studio for macOS.

## Local project data

Lyreline Studio stores managed Studio project information and generated assets
locally on your Mac. Files are copied or exported elsewhere only when you choose
an import, export, handoff, relink, or save destination. Portable Studio packages
contain the project information and assets needed for the supported package
workflow.

## Files you select

Lyreline Studio is sandboxed. It accesses source recordings, audio, Studio
packages, and output destinations that you explicitly select through macOS. The
app uses macOS security-scoped access where required so it can use those selected
files.

## Apple Speech

Apple Speech uses speech services and voices provided through macOS. Available
voices and system behavior depend on the Mac and its installed Apple software.

## OpenAI Speech

OpenAI Speech is optional. If you provide an OpenAI API key, Lyreline Studio
stores it in macOS Keychain. The key is not written into Studio project files or
standard app preferences.

When you explicitly select OpenAI Speech and initiate narration generation, the
narration text required to generate speech is sent to OpenAI using the API key
you provide. Testing the OpenAI connection also contacts OpenAI using that key.
No OpenAI request occurs merely by launching Lyreline Studio.

OpenAI processes those requests under its own terms and privacy policies.
Lyreline Studio does not control OpenAI's processing or retention practices.

## Analytics, tracking, and advertising

The current Lyreline Studio application contains no analytics, advertising,
tracking, or third-party telemetry SDK. It does not include advertising.

## Accounts and purchases

Lyreline Studio does not provide a Lyreline Studio account system. Mac App Store
purchases and payment information are handled by Apple; Lyreline Studio does not
directly process credit-card or payment details.
