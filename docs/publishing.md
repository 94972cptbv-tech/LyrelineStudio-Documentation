# Publishing

Lyreline Studio can create three customer-controlled output types from the
current publication document.

## HTML

HTML publication creates a browsable document with sections, figures, and
navigation. Preview it in Studio before choosing the export destination.

## PDF

PDF publication produces a paginated document with selectable text, navigation,
and supported accessibility descriptions. Page breaks and image fitting may
differ from the HTML presentation.

## Video

Video publication combines section timing, visuals, narration, motion, and
configured gaps into an MP4 file. Preview the final video and confirm source
media is available before exporting.

## Publication status

After a successful publication, Studio records durable evidence of the output's
format, creation date, and the project state used to produce it. Studio can then
show whether an output is current or out of date. The record is status evidence;
it is not a hidden copy of the exported file.

If authored or narration content changes, review those upstream changes first.
Studio then guides you to update stale publications.

## Output files and source media

You choose where exported HTML, PDF, and video files are written. Moving or
deleting an exported file does not delete the Studio project.

Source recordings may be referenced separately from the managed project. If a
recording moves, use Studio's relink action to select it again. Relinking does
not change the project's identity.
