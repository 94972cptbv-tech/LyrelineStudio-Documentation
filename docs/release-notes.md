# Release Notes

## Lyreline Studio 1.0

The first public release includes:

- Studio project management, archiving, restoration, and portable packages
- continuation with Lyreline for capture and procedure authoring
- review of authored source updates while preserving Studio narration work
- narration drafting and imported audio
- Apple Speech and optional OpenAI Speech generation
- HTML publication and preview
- PDF publication and preview
- narrated video preview and MP4 publication
- publication status for current and out-of-date outputs
- source-recording relinking and recovery
- Studio package import and export

For the complete capture-and-authoring workflow, Lyreline is also required.
