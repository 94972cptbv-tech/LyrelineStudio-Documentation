# Release Notes

## Lyreline Studio 1.4

**More precise storytelling in Lyreline Studio.**

Lyreline Studio now gives you finer control over how narration, visuals, and
annotations work together:

- Synchronize visuals with selected narration phrases using Visual Cues, then
  adjust the timing earlier or later when needed.
- Add natural narration pauses that carry through Section Preview, Final Video
  Preview, and exported video while the current visual remains on screen.
- Continue numbered Callout Sequences across multiple visuals in a section.
- Reorder visuals directly in the Section Editor; playback, visual timing, and
  Callout Sequence numbering follow the new order.
- Select Visual Timing / Details rows directly while editing.
- Customize Highlight color and transparency, or reset a Highlight to the
  original Lyreline yellow appearance.
- Benefit from improved narration editing, reordered visual playback, preview
  and export synchronization, and Section Editor reliability.

Existing projects remain compatible with Lyreline Studio 1.4.

## Lyreline Studio 1.0

The first public release includes:

- Studio project management, archiving, restoration, and portable packages
- continuation with Lyreline for capture and procedure authoring
- review of authored source updates while preserving Studio narration work
- narration drafting and imported audio
- Apple Speech and optional OpenAI Speech generation
- HTML publication and preview
- PDF publication and preview
- narrated video preview and MP4 publication
- publication status for current and out-of-date outputs
- source-recording relinking and recovery
- Studio package import and export

For the complete capture-and-authoring workflow, Lyreline is also required.
