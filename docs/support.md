## Before requesting help

Open **Lyreline Studio > About Lyreline Studio** and note the version and build.
Also note your macOS version, the action you were attempting, and the exact error
wording.

Do not send passwords, API keys, confidential project packages, sensitive
recordings, or private screenshots. Attach a screenshot only when it is safe to
share.
