# Lyreline Studio

**Capture and author in Lyreline. Narrate, organize, and publish in Lyreline Studio.**

Lyreline Studio is the publication and narration companion to Lyreline. It keeps
long-lived Studio projects organized while you prepare narration, review source
updates, and publish customer-controlled HTML, PDF, and video files.

## What Lyreline Studio provides

- Studio project creation, organization, archiving, and recovery
- narration drafting and generated speech
- Apple Speech and optional OpenAI Speech
- review of authored updates returned from Lyreline
- HTML, PDF, and video publication
- publication status that helps identify current and out-of-date outputs
- source-media relinking when a referenced recording moves

## The complete workflow

Lyreline owns capture, screenshots, annotation, procedure authoring, and the
canonical instructional content. Lyreline Studio owns narration and publication
work built from that content.

**For the complete capture-and-authoring workflow, Lyreline is also required.**
Lyreline Studio 1.0 does not include Lyreline's full capture and procedure editor
inside the Studio app.
