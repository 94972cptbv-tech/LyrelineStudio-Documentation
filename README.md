# Lyreline Studio Documentation

Public customer documentation, support information, and privacy information for
Lyreline Studio.

## Local preview

Install MkDocs, then run:

```sh
mkdocs build --strict
mkdocs serve
```

The proposed GitHub Pages repository is `LyrelineStudio-Documentation`. The
public site is not live until the repository is created, this content is
published, GitHub Pages is enabled, and the resulting URLs are verified.
